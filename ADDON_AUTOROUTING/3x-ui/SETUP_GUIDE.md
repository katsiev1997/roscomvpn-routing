# Настройка маршрутизации в 3x-ui: Clash Verge + блокировка RU на сервере

Гайд для повторной настройки с нуля. Состоит из двух независимых частей:

1. **Клиент (Clash Verge):** правила подписки, чтобы RU-трафик шёл напрямую, остальное через VPN.
2. **Сервер (Xray):** страховка, которая блокирует трафик на RU-сайты, если он всё же попал на сервер.

> Проверено по исходникам основного 3x-ui (`internal/sub/clash_service.go`, `remote_routing.go`).
> Форк hydraponique/3x-ui делает роутинг для Happ и Xray, вкладки Clash/Mihomo в нём нет.

---

## Часть 1. Правила в Clash-подписке

### Где настройка
Панель → **Настройки** → **Подписка** → вкладка **Clash / Mihomo**.

### Шаги
1. Включите **«Включить маршрутизацию»**.
2. Откройте файл `MIHOMO/template_3xui.yaml` из этого репозитория, скопируйте всё содержимое.
3. Вставьте в поле **«Глобальные правила маршрутизации»** вместо старого текста.
4. Оставьте **«DNS из удалённых правил»** выключенным (он нужен, только если вы берёте файл по ссылке и хотите разделы `dns`/`sniffer` оттуда).
5. Сохраните.
6. В Clash Verge обновите профиль (подписка должна быть по адресу `/clash/<subId>`).

### Проверка
Откройте `https://<панель>/<путь-подписки>/clash/<subId>` в браузере. В YAML должны быть
`proxy-groups`, `rule-providers`, `rules`. Затем обновите профиль в Clash Verge.

### Что делает файл
- Группа `PROXY` с `include-all: true` подтягивает все ваши узлы.
- Группы `⚡️ Авто`, `📺 Youtube`, `💬 Discord.exe`, `🎮 Игры`.
- 28 rule-providers RoscomVPN (реклама, телеметрия, игры, RU-сайты, Telegram и др.).
- Ваши `DOMAIN-SUFFIX,...,DIRECT` и `GEOIP,RU,DIRECT,no-resolve` в конце.

### Как работает панель (важно знать)
- **Ручная вставка текста.** Ключ `rules` добавляется перед базовым `MATCH,PROXY`. **Все остальные ключи заменяют базовые целиком**, поэтому в файле есть своя группа `PROXY`.
- **Ссылка (HTTPS).** Панель загружает файл в фоне (таймаут 6 с, до 2 МБ, только публичный HTTPS), кэширует на 10 минут. Берёт только `proxy-groups`, `rule-providers`, `rules` (и `dns`/`sniffer`, если включён переключатель). Ссылки на несуществующие группы дают ошибку подписки.
- **`/clash-legacy/`** правила не получает.
- Формат `payload:` не работает. Нужен ключ `rules:` или просто строки правил.

### Если не заработало
| Симптом | Причина |
|---|---|
| Правил нет в подписке | Старый кэш: подождите минуту, обновите. Проверьте, что адрес `/clash/`, а не legacy |
| Ошибка про «unknown proxy or group» | Правило ссылается на группу, которой нет в файле |
| Правила из `payload:` не применяются | Замените `payload:` на `rules:` |
| Вставка обрезалась | Слишком длинный файл: оставьте `rules` и нужные провайдеры |

## Часть 2. Блокировка RU-трафика на сервере (Xray)

### Где настройка
Панель → **Настройки Xray** → **Маршрутизация**.

### Шаги
1. Нажмите **«ещё»** → импорт (или **«+ Маршрутизация»** и добавьте два правила вручную).
2. Импортируйте:

```json
[
  {
    "type": "field",
    "domain": [
      "domain:ru",
      "domain:su",
      "domain:xn--p1ai",
      "domain:vk.com",
      "domain:vk-cdn.net",
      "domain:userapi.com",
      "domain:yandex.com",
      "domain:yandex.net",
      "domain:yastatic.net",
      "domain:mycdn.me",
      "domain:ok.ru"
    ],
    "outboundTag": "blocked"
  },
  {
    "type": "field",
    "ip": ["geoip:ru"],
    "outboundTag": "blocked"
  }
]
```

3. Порядок: правило `api` остаётся первым, новые правила идут ниже.
4. **Сохраните и перезапустите Xray.**

### Обязательные условия
- На инбаундах включён **sniffing** (HTTP, TLS, QUIC). Без него доменные правила не работают.
- На сервере есть актуальный `geoip.dat` (для форка hydraponique это `geoip_ROSCOM.dat`).

### Проверка
Вкладка **«Тест маршрута»**: `yandex.ru` → `blocked`, `google.com` → не `blocked`.

### Если зарубежные сайты перестали открываться
Сначала отключите правило `geoip:ru`. Оно единственное может давать ложные срабатывания (CDN).

## Чек-лист при новой установке
- [ ] Обновить панель до версии с вкладкой Clash / Mihomo
- [ ] Вставить `MIHOMO/template_3xui.yaml` в поле глобальных правил, сохранить
- [ ] Обновить подписку в Clash Verge, проверить `/clash/<subId>` в браузере
- [ ] Импортировать два серверных правила Xray (домены и `geoip:ru`)
- [ ] Включить sniffing на инбаундах
- [ ] Сохранить и перезапустить Xray
- [ ] Проверить через «Тест маршрута» и в Clash Verge (RU напрямую, остальное через VPN)
